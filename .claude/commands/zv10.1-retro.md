# Engineering Retrospective (Optional, Periodic)

Analyzes commit history, work patterns, and shipping velocity. Run weekly or after a major milestone.

## Arguments
- `/zv10.1-retro` — last 7 days (default)
- `/zv10.1-retro 24h` — last 24 hours
- `/zv10.1-retro 14d` — last 14 days
- `/zv10.1-retro 30d` — last 30 days
- `/zv10.1-retro compare` — this period vs prior same-length period

## Step 1: Gather Data

```bash
git fetch origin main --quiet
```

Run in parallel:
```bash
git log origin/main --since="<window>" --format="%H|%aN|%ae|%ai|%s" --shortstat
git log origin/main --since="<window>" --format="" --name-only | grep -v '^$' | sort | uniq -c | sort -rn | head -20
git shortlog origin/main --since="<window>" -sn --no-merges
git log origin/main --since="<window>" --format="%s" | head -100
TZ=America/Los_Angeles git log origin/main --since="<window>" --format="%at|%aN|%ai|%s" | sort -n
```

## Step 2: Metrics

| Metric | Value |
|--------|-------|
| Commits to main | N |
| Total insertions | N |
| Total deletions | N |
| Net LOC | N |
| Active days | N |
| Detected sessions | N |

Session detection: 45+ min gap between commits = new session.

## Step 3: Commit Type Breakdown

ASCII bar chart by conventional commit prefix (feat, fix, style, refactor, chore, docs).

## Step 4: Hotspot Analysis

Top 10 most-changed files. Flag files changed 5+ times.

## Step 5: Work Patterns

Commits by hour (Pacific time). Session summary: total, avg length, avg commits/session.

## Step 6: Compare Mode (if requested)

| Metric | This Period | Last Period | Delta |
|--------|-------------|-------------|-------|

## Step 7: Narrative

3-5 sentences: theme, what went well, what to improve, next week's focus.

## Output

Save to `ai/zv/retros/YYYY-MM-DD-retro.md`. Create directory if needed.

If compare mode, also save JSON to `ai/zv/retros/YYYY-MM-DD-retro.json` for trend tracking.
